## Image Optimization Tips

1. **Format**: Use JPG for photos, PNG for graphics with transparency
2. **Optimization**: Compress images using tools like:
   - [Squoosh](https://squoosh.app/) (web-based)
   - ImageOptim (Mac)
   - TinyPNG (web-based)
3. **Sizes**: 
   - Hero images: 1920px width, ~80% quality
   - Card thumbnails: 800px width, ~85% quality
   - Gallery images: 1200px width, ~85% quality
   - Profile photo: 400x400px, ~90% quality
4. **Alt Text**: All images already have alt text in HTML - update them with descriptive text

## Placeholder Images

If you don't have images yet, you can:
1. Use placeholder services like [Placeholder.com](https://placeholder.com/)
2. Create simple colored rectangles as placeholders
3. Use stock photos temporarily (replace with your own later)

The site will work without images, but they will show as broken image icons until you add them.
